A stochastic, discrete time, per-state compartmental model (CM) of the COVID-19 disease within Australia (June 1st, 2021 to June 30th, 2022) is constructed, where model parameters are calibrated using historical data.
The historical level of vaccine hesitancy is then replaced with independent counterfactual scenarios of higher vaccine hesitancy, to predict the impact on dependent COVID-19 cases and associated deaths.
The .xlsx files are required to calibrate model parameters.
